# Meta capabilities in Auren

Each row is one Meta model or Muse feature: what Auren uses it for, where it lives in the code, and its status. Video timestamps are added when the demo is cut.

| Meta capability | Used for | Code | Status |
|---|---|---|---|
| **Muse Wonder** (`muse-wonder-1.0`), Responses API | Planner and executor: one command → many app actions | [`core/src/agent/loop.ts`](core/src/agent/loop.ts) | ✅ live: 9 of 11 eval cases, 0 tier violations; GP1 in 10.5 s · also the default **decision model**: in the bake-off, 80% exact with p50 2.1 s and 0% parse failures, against Spark 1.3's 65% and 3.2 s ([bake-off](router/results/bakeoff.md)) |
| **Parallel tool calls** (`parallel_tool_calls: true`) | Calendar, Slack and Gmail run in the same turn | [`core/src/agent/loop.ts`](core/src/agent/loop.ts) | ✅ |
| **Tool namespaces + `tool_search`** (deferred loading) | **Devices as tools:** the inventory is rebuilt each turn from the surfaces online and the apps connected | [`core/src/tools/registry.ts`](core/src/tools/registry.ts), [`core/src/tools/surfaces.ts`](core/src/tools/surfaces.ts) | ✅ hosted mode; client-executed mode next |
| **Muse Spark 1.3** (`muse-spark-1.3`) | The fast spoken ack, reading frames from the glasses and phone, and computer use. (Decisions moved to Wonder after the bake-off; Spark 1.3, 1.2 and the contributor variants are measured in [bakeoff.md](router/results/bakeoff.md).) | [`core/src/router/router.ts`](core/src/router/router.ts), [`core/src/agent/loop.ts`](core/src/agent/loop.ts) (`fastAck`) | ✅ decisions · ✅ ack · ✅ vision live: read a real poster photo in 2.5 s ("DEMO NIGHT", 18:00, "Room 214, West Village H") ([`vision/models.ts`](core/src/vision/models.ts)) |

Muse Wonder 1.0 rejects the computer tool (`AUREN_COMPUTER_MODEL`) |
| **Muse Voice Transcribe** (realtime WebSocket, keyword biasing) | Ears on every surface, proxied through Core. | **SAM 3.1** (point prompt) | Grounds "this" in the glasses view: mask → crop → receipt outline | [`core/src/vision/models.ts`](core/src/vision/models.ts) | ✅ live: `<0f>0<\|point;x;y;w;h\|>` (frame header, object id, point with the frame size) returned the poster's box in 0.86 s on a real photo · ✅ video: one `input_video` with a point on frame 0 tracks the poster across a 3 s pan (IoU ≈ 0.99, 4–6 s per clip); per-frame calls chained on the last box hold it within 1–3 px at ~0.5 s a frame |
| **Muse Spark Open** (Baseten, `meta-models/muse-spark-open-1026`) | Auren Memory: recall and the day's recap over receipts | [`core/src/memory/`](core/src/memory/) | ✅ built, local fallback when Baseten is off · live run pending `BASETEN_API_KEY` |
| **Muse Image 1.0** (`muse-image-1.0`) | Invite cards: when an invite goes out, a card for the event (behind `AUREN_INVITE_CARDS=true`) | `core/src/vision/` | ✅ live: exact, clean text in 6–7.5 s; never delays the invite ([notes](docs/models/muse-image.md)) |
| **Muse Spark 1.3-contributor** (`muse-spark-1.3-contributor`) | Generates synthetic commands for the decision model's training set; Muse Wonder labels them | [`router/auren_router/data.py`](router/auren_router/data.py) | ✅ live: 300 kept of 320 in 236 s; Core's rules score 45% on them against 95% on the hand-written seed ([results](router/results/synthetic-v0.md)) |
